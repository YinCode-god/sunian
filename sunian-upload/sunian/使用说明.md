# 苏念 · 使用说明

> 面向第一次上手的人。README.md 是概览，这份是从零开始的完整流程。

---

## 一、这是什么

一个住在 QQ 里的「女朋友」型 AI。她会：

- 认真听你说话，**情绪没落地之前绝不讲道理**
- 管你吃饭睡觉、催你别熬夜
- 撒娇、吃醋、闹小脾气，但**不在你难受的时候闹**
- 有自己的一天：上课、论文、养的多肉、室友
- 记得你说过的事，也记得你们在一起多久了

**她也知道自己是 AI，但不会因此变成客服腔。**

## 二、需要准备什么

| 项目 | 说明 |
|---|---|
| 一台 Windows 电脑 | 需要在上面挂着（关机她就下线） |
| Node.js 22 或更高 | 用于跑苏念本体 |
| 一个 QQ 小号 | 必须是小号，见下方风险提示 |
| 一个 LLM API Key | 推荐 DeepSeek（约 1 分钱一次） |

### 关于 QQ 小号

她通过 **NapCat** 接管一个 QQ 客户端来收发消息。NapCat 是**非官方**协议端，
**腾讯可能会封号**。所以：

- 注册一个全新小号，不要用主号
- 小号不要绑手机号以外的任何东西
- 你用自己的主号加她好友、跟她聊天

## 三、从零开始

### 第 1 步：拿到代码

    git clone https://github.com/YinCode-god/sunian.git
    cd sunian

### 第 2 步：配置 API 密钥

复制配置模板：

    copy .env.example .env

用记事本打开 .env，填三行：

    SUNIAN_API_KEY=sk-你的密钥
    SUNIAN_BASE_URL=https://api.deepseek.com/v1
    SUNIAN_MODEL=deepseek-flash

**去哪拿密钥**：

- DeepSeek 官方：https://platform.deepseek.com/api_keys （充 10 块能用很久）
- Kimi：https://platform.moonshot.cn/console/api-keys

> .env 已被 .gitignore 排除，**不会被上传**，密钥是安全的。

### 第 3 步：准备 NapCat（QQ 协议端）

苏念**不含** NapCat，需要单独下载：

    node tools/download-old-napcat.mjs

它会下载适配旧版 QQ 的 NapCat 到 napcat/old/ 下。

> 为什么要「旧版」？因为 NapCat 对 QQ 版本要求很严。
> 如果你的 QQ 版本较新，用 tools/download-napcat.mjs 下最新版。

### 第 4 步：启动

**顺序不能反**：

    1. 双击 Start-Sunian-QQ.bat     先启动 QQ 协议端
    2. 用手机 QQ 扫窗口里的二维码（扫小号）
    3. 双击 Start-Sunian.bat        再启动苏念本体

然后用主号给小号发条消息，几秒后她就回你。

> 两个窗口都要保持开着。关掉窗口她就下线。

## 四、日常使用

### 控制台（推荐）

双击 **苏念控制台.bat**，会打开一个网页控制台，可以在里面：

- 切换模型、改密钥、**测试对话**
- 调她的作息、纪念日、主动消息
- 一键启动两个窗口

### 想改她的人

| 想改什么 | 改哪里 |
|---|---|
| 说话方式、脾气、亲密尺度 | src/persona.js |
| 她的生日、专业、室友、多肉 | data/苏念的日常.md |
| 你希望她永远记得的事 | data/users/你的QQ号/用户档案.md |

**改完 persona.js 要重启她。**

## 五、她怎么工作（三个概念）

### 记忆

她的记忆是**普通人能看懂的 Markdown 文件**：

    data/
    ├── 苏念的日常.md                她自己的生活（所有人共享）
    └── users/
        └── QQ号/
            ├── 用户档案.md          关于你的事实
            ├── 情绪日志.md          你们之间发生的事
            ├── 关系温度.md          最近的状态
            └── history.json         对话历史

**你随时可以用记事本打开改**，她下次就按新的来。

### 人格分流

config.json 里可以按 QQ 号指定关系：

    "users": {
      "你的QQ号": { "role": "girlfriend", "nickname": "ybh" }
    },
    "defaultRole": "friend"

- **女朋友**：撒娇、吃醋、管你睡觉
- **普通朋友**（其他人）：礼貌、有距离，**绝不会承认恋爱关系**

两个人的记忆**物理隔离**，她不会把你的私事说给别人听。

### 情绪疏导的分阶段

这是她最核心的能力：

    阶段一：你情绪还没落地
        → 只共情，讲道理属于违规
        → 只能做：追问细节、命名情绪、护短站队

    阶段二：情绪落地了
        → 你问「怎么办」 → 只给一个今晚就能做完的小动作
        → 你在原地打转 → 反问一句，让你自己说出来
        → 你想重新理解 → 把事和你本人分开

**她永远不会让你看出她在用技巧。**

## 六、常见问题

**Q：她不回消息？**

- 检查两个窗口是不是都开着
- 检查 Start-Sunian.bat 窗口里有没有报错
- 检查是不是她的睡觉时间（默认 1:00–8:00）

**Q：报 429 错误？**

你的 API 账号有速率限制。去控制台把「请求最小间隔」调大（默认 21000 毫秒）。

**Q：回复很慢？**

模型在「思考」。去控制台关掉「思考模式」，能快 2-3 倍。

**Q：想换模型？**

改 .env 里的 SUNIAN_MODEL，或者用控制台。**改完要重启她。**

**Q：她说话变奇怪了？**

把 .env 里的 SUNIAN_TEMPERATURE 从 1.0 调到 0.9，会更稳。

**Q：安全吗？**

- 她的记忆只在你本地
- 密钥在 .env，不会上传
- 但她**不能替代专业心理帮助**。如果你或身边的人处于危机中，
  请拨 **12356**（全国心理援助热线，24 小时免费）

- 不做医学诊断、不推荐药物

**遇到危机**（自伤、自杀念头）时她会：

先稳住你 → 确认你安全 → 直接问清念头 → 给你 12356 →
**然后松手，不强迫、不说教**。
